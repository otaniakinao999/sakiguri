# 検証用のサンプルファイル

## 銀行明細-shift_jis.csv（AC-07）

Shift_JIS の銀行CSV。**UTF-8 として厳格デコードすると必ず失敗する**バイト列に
なっているので、CL-7 の文字コード判定の分岐を実際に通せる。半角カナ
（0xA1〜0xDF の1バイト文字）が UTF-8 として不正なためである。

```
日付,摘要,お預入,お引出,残高
2026/9/22,ﾃﾞﾝｷﾀﾞｲ ９月分,,5000,758000
2026/9/28,ｺﾝﾋﾞﾆ ATM ﾃｽｳﾘｮｳ,,220,757780
2026/10/20,ﾌﾘｺﾐ ｼﾞﾑｼｮﾔﾁﾝ,,100000,657780
2026/10/25,ﾌﾘｺﾐ ｶ)ｻｷｸﾞﾘ 売上,500000,,1157780
```

改行は CRLF。摘要はわざと半角カナにしてある。**銀行のCSVはこれが普通で、
費目の自動推定（名称の先頭4文字を摘要に部分一致）はこの形式にはほぼ当たらない。**
4行目の「売上」だけが漢字なので推定に当たる。

検証用アカウントのデータと組み合わせると、4行中3行が自動照合される。

| 行 | 照合先 |
|---|---|
| 9/22 −5,000 | 電気代（変動）9/22 |
| 9/28 −220 | なし |
| 10/20 −100,000 | 事務所家賃 10/20 |
| 10/25 +500,000 | 売上 10/25 |

作り方。

```bash
iconv -f UTF-8 -t SHIFT_JIS bank-utf8.csv > 銀行明細-shift_jis.csv
```

**このファイルを UTF-8 に変換して保存し直さないこと。** 変換するとテストの
意味が無くなる。エディタの自動変換に注意する。
