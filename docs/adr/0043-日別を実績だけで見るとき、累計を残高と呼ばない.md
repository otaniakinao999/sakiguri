# ADR-0043 日別を実績だけで見るとき、累計を残高と呼ばない

日付：2026-11-15
関連：FR-66・AC-75・AC-71・AC-49a・AC-49c、CLAUDE.md §2.11・§2.12

## 文脈

口座ごとの日別の表（FR-64）は**予測系列から作っている**（AC-49a）。
出納帳には**予定の行が無い**ので、1行ずつ突き合わせると予定の日で止まる。

**実績だけで見る切り替えが要る**（FR-66）。ただし、素直に作ると2つ踏む。

1. 実績系列から「残高」を出すと、**同じ日について画面に2つの残高が出る**
   （AC-49c）。`core/account-daily.ts` が予測系列を選んでいるのはこの理由
   である。
2. 入出金予定表が**同じ画面で**「予定+実績／予定のみ／**実績のみ**」を
   使っている。日別の切り替えを「実績のみ」と呼ぶと、**同じ画面に同じ
   言葉が2つ並び、どちらが効いているか利用者には区別できない。**

## 判断

### 1. 「出納帳と合わせる」と呼ぶ（目的で名づける）

「実績のみ」と呼ばない。**範囲が違うものに同じ名前を付けない。**

### 2. 累計を「残高」と呼ばない

| | 予測（既定） | 出納帳と合わせる |
|---|---|---|
| 列 | 残高 | **実績の累計** |
| 期首 | 期首残高 | **期首の累計** |
| 期末 | 期末残高 | **期末の累計** |

**語はビューモデルが渡す**（`CashflowDaily.labels`）。画面が系列を見て
語を選ぶ形にすると、**表の見出し・期首の行・式の文で別々に選ぶ**ことに
なる（§2.8）。

**値の名前も変えた。** `AccountDailyRow.balance` → `running`。実績だけの
ときは残高ではないので、その名前で持つと**次に読む人が画面に「残高」と
出す**（§2.12 はコードではなく画面の値の重複を扱う条項だが、名前が
そこへ誘導する）。

### 3. 必ず合う式を画面に出さない

AC-71 の留め具「期首 ＋ 増減の合計 ＝ 期末」は、**予測のときだけ効く。**
予測では**増減を行から足し、残高を系列から取る**ので、二重に数えたり
落としたりすると割れる。

**実績だけのときは累計を行から積むしかない。** 系列は口座別の実績残高を
持っていない（`byAccount` は予測系列。`act` は範囲の合計で、範囲がその
口座と同じとは限らない）。したがって「期末 − 期首」は増減の合計と
**一致するしかない**（§2.11 の4つ目の形）。

**だから画面にも出さない。** 代わりに「行から積んでいるので必ず一致する
（確かめにはなりません）」と書く。**必ず合う式を『合っている』と読ませ
ない。**

### 4. カードの引落を「予定」と数えない

実績系列にも引落の行は在る（基準日の未払や、記録した利用が引き落とされる
日）。`src` が `actual` でないという理由で数えると、**出納帳に在る行に
「予定1件」と出る**（2026-11-15 に実機で見つけた）。実績だけのときは
`planCount` を数えない。

## 却下した選択肢

### 実績の累計を `series.rows[].act` から取る

**留め具が生きたまま残る**（増減と累計が別々の出どころになる）。退けた。

`act` は**範囲（`scope`）の合計**であって、口座別の実績残高ではない。
いまの画面では範囲＝選んだ口座なので一致するが、**その一致は呼び出し側の
都合であって、`buildAccountDaily` には確かめようがない。** 範囲を広げた
呼び出しが1つ増えた瞬間に、黙って違う値が出る。

**留め具が1つ死ぬほうを採った。** 死んでいることを画面にも書いてある。

### 既定を「出納帳と合わせる」にする

退けた。**ダッシュボードの残高と日別の表が、既定どうしで食い違う**
（AC-75）。

## 影響

- `AccountDailyRow.balance` を `running` に改名した（呼び出しは3箇所）。
- 切り替えは**画面の状態で、保存しない。** 口座の選択と同じ扱い。
- **測るには予定が要る**（§2.11 の4つ目の形）。未記録の予定が0件の口座で
  測ると、切り替えても結果が同じで**実装していなくても通る。** 現金（a0）
  は実績2件だけなので使えない ―― 検査は○○銀行（a1）で測る。
- カードの未払が0だと、上の4を測れない（引落の行が立たない）。核の検査は
  基準日の未払を持つ一式を別に組んである。
