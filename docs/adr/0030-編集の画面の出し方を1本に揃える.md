# ADR-0030 編集と「この回だけ」の画面の出し方を `Modal` 1本に揃える

2026-11-12 ／ FR-55・AC-59・AC-60

## 文脈

同じ「実績を編集」に**3つの出し方**があった。

| 経路 | 出し方 | どこに開くか |
|---|---|---|
| やること → 実績を編集 | `Modal` | 画面の中央 |
| やること → 払えなかった | `DeferralEditor` を `dialog` スロットに裸で | ページの**末尾** |
| キャッシュフロー明細 → 項目名 | インラインの箱 | 入出金予定表の**上端** |

利用者の報告はこうだった。

> 払えなかった押した時に、今回はなしボタンを含むこの回だけ動かすエリアが
> 一番下に出て見つからないのが問題かも。**俺が見つけられなくて今気づいた。**

**「期間絞り込みで明細のリンクが動作しない」という別の報告も、同じ欠陥だった。**
ビューモデルは絞り込んでも `actualId` を保ったままで、押せば開いていた。
**開いていたのに、表の上端なので画面の外にあった。**

`Modal` は Esc で閉じ、開いているあいだ背後のスクロールを止める。
**その仕組みは1経路にしか付いていなかった**ので、ほかの2経路には閉じる
手段が［やめる］しか無かった。

## 決めたこと

**3経路とも `Modal` を通す。**

- `DeferralEditor` は自分の `Card` と［閉じる］を捨てる。題と［閉じる］と
  Esc は `Modal` が持つ
- キャッシュフローのインラインの箱をやめ、`CashflowView` の `ledgerEditor`
  （明細の上）を `dialog`（画面の末尾）に替える。`Modal` は `fixed` なので、
  置き場所に関わらず画面の中に出る
- `Modal` の `z-index` を 30 → **40** に上げ、追従バー（20）より上にする

**［実際の金額］に打った額を繰延に引き継ぐ**（AC-59）。`onDefer` が額を
受け取り、`DeferralEditor` が `initialAmount ?? plan.amount` で初期化する。
**`plan` には混ぜない** ―― 「実際に変えたものだけを書く」判定が
`plan.amount` との比較なので、混ぜると打った額が記録から落ちる。

**`Modal` は `ui/legacy/` に置いたまま**にした。v0.6.0 のトークンへ移すと
面の色と角丸が変わる。出し方を揃える変更に見た目の変更を混ぜない
（CLAUDE.md §2.6 の14ファイルと同じ扱い）。

## 理由

**押した場所から見えない画面は、開いていないのと同じ。** 利用者は自分で
押したのに見つけられなかった。`fixed` な覆いなら、どこを見ていても必ず
画面の中に出る。

**閉じる手段を1箇所に集めると、経路を足しても付け忘れが起きない**（§2.8）。
いまは Esc と背後のスクロール固定が `Modal` にしか無い。

## 却下した選択肢

| | なぜ却下したか |
|---|---|
| 押した行の直下にアコーディオンで開く | 行の高さが変わって表が跳ねる。明細は仮想化していないので、下の行が全部ずれる。利用者も「変な場所に出るくらいならモーダルとかアコーディオン」と並列に挙げていて、モーダルで条件を満たす |
| インラインの箱を押した行の近くへ移す | 「近く」は距離の問題ではなく、**画面の外かどうか**の問題。箱を移しても、絞り込みで行が動けばまた外に出る |
| `Modal` を v0.6.0 のトークンへ移してから揃える | 見た目が変わる。欠陥の修正と混ぜると、どちらが原因で見え方が変わったのか分からなくなる |
| Radix の `Dialog` を入れる | 依存が増える（§2.7）。`Modal` に Esc・スクロール固定・フォーカス移動は既にある |

## 影響

- `CashflowViewProps.ledgerEditor` → `dialog`。描画位置が明細の上から画面の
  末尾に変わる
- `DeferralEditor` は単体では面を持たない。`Modal` の中でしか使えない
- 重なり順：表の固定セル 10 ＜ 追従バー 20 ＜ 覆い 40 ＜ `AlertDialog` 50
- 測り方は `entry/__tests__/edit-dialog.test.ts` と
  `cashflow/__tests__/edit-dialog.test.ts`（jsdom）。**覆いが出ること・
  背後がスクロールしないこと・Esc で閉じること**を3経路で測る。
  「開くこと」だけでは足りない ―― **以前も開いてはいた**
- **位置と重なりは測れない**（jsdom にレイアウトエンジンが無い）。実機で見た
