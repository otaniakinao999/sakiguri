# 0006. core の日付計算に Date オブジェクトを使わない

## 文脈

[ADR-0002](0002-日付を文字列で持つ.md) で、日付は `'YYYY-MM-DD'` の文字列で持つと決めた。CLAUDE.md §2.2 はそのうえで「`Date` オブジェクトは月末計算などの内側だけで使い、境界では必ず文字列に戻す」としている。

プロトタイプはこの方針で書かれている。

```js
const lastDayOf = (y, m) => new Date(y, m + 1, 0).getDate();
const addMonths = (d, n) => new Date(d.getFullYear(), d.getMonth() + n, 1);
```

`new Date(y, m, d)` はローカルタイムゾーンで解釈されるため、JST 環境では正しく動く。問題は、`Date` が視界に入っている限り `toISOString()` や `getTime()` を足せてしまうことである。CL-1 の月末寄せ、CL-2 の引落日、CL-8 の返済日、CL-9 の入金予定日はいずれも月境界の計算であり、1日ずれると締めの判定が壊れる（PoC開発計画 §5.3）。

## 判断

`src/core/date.ts` で **`Date` を一度も使わない。** 閏年と月末を算術で求める。

```ts
const isLeapYear = (y) => (y % 4 === 0 && y % 100 !== 0) || y % 400 === 0;
const lastDayOfMonth = (y, m) => (m === 2 ? (isLeapYear(y) ? 29 : 28) : DAYS_IN_MONTH[m - 1]);
```

月の加減算も `year * 12 + (month - 1) + n` の整数演算で行う。日付ユーティリティは `src/core/date.ts` の1箇所だけに置き、CL-1／CL-2／CL-8／CL-9 がすべてそこを呼ぶ。

## 理由

CLAUDE.md §2.2 は `Date` の使用を許容しているが、**使う理由がない。** 必要なのは閏年判定と月末日数だけで、どちらもグレゴリオ暦の規則そのものであり、10行に満たない。

`Date` を持ち込まなければ、UTC 変換もローカルタイムゾーン依存も**原理的に**起きない。「JST 環境なら正しく動く」ではなく「どの環境でも同じ結果になる」になる。これは CLAUDE.md §2.3 が core に求める「入力を渡すと同じ出力が返る」を満たすうえで直接効く。

副次的に、`Date` を import していないことが grep で確認できる。規約の遵守を目視ではなく検索で確かめられる。

## 却下した選択肢

**プロトタイプどおり `new Date(y, m, d)` を内側で使う。** JST 環境では正しく動く。ただし `Date` が手元にある状態が続くため、後から `toISOString()` や `getTime()` が混ざる余地が残る。混ざったときに落ちるのはテストではなく本番の締め判定であり、しかも1日ずれるだけなので気づきにくい。

**`Temporal` API（`Temporal.PlainDate`）を使う。** 用途にはまさに合致する。ただし対応環境（要件定義書 5.5：Chrome / Safari / Edge の最新2バージョン）での可用性が読めず、polyfill を入れると CLAUDE.md §2.7 の依存許可リストを増やすことになる。得られるものが10行の算術の置き換えに留まるため見送った。将来 polyfill 無しで使えるようになれば再検討の価値がある。

**Intl.DateTimeFormat でタイムゾーンを明示する。** `Date` を残したままタイムゾーンを固定する案。文字列整形のたびに Intl を通すことになり、単純な算術より遅く、複雑になる。

## 影響

- `src/core/date.ts` は `Date` を import しない。他の core モジュールも同様
- `parseDate` は 4桁-2桁-2桁 の書式と、日付の実在（`2026-02-30` を弾く）を検証する
- グレゴリオ暦の規則のみを実装しているため、和暦・非グレゴリオ暦は扱えない。要件定義書 CL-7 が「和暦は対象外」としているため問題にならない
- `Date` が要るのは「今日は何日か」を得る場面だけであり、それは core の外（UI 層）の責務になる。core は `today: DateStr` を引数で受け取る（CLAUDE.md §2.3）
