## 1. 形を押さえる ―― 守りがどこに1本しか無いか

ブラウザが publishable key を持って**Postgres に直接話す。** 自前のサーバーが間に無い。だから守りの相手ごとに、効く仕組みが違う。

| 相手 | 効いているもの | 状態 |
|---|---|---|
| **他の利用者** | RLS（8表 × 4本） | **厚い。** 48通りの検査が控えている |
| **自分のページで動くスクリプト** | CSP | **report-only で入れた。** 強制はまだ（下の2） |
| **盗まれたセッション** | セッションの寿命・パスワード方針・2段階 | **測った。** 60分・6文字・漏洩の照合は無効・2段階なし（下の3） |

**RLS は上の1行目にしか効かない。** 差し込まれたスクリプトはサインイン済みの本人として動くので、RLS からは正しい利用者に見える。

**2行目は半分になった。** CSP は入ったが report-only で、しかも
`'unsafe-inline'` が要る（下の2）。**止まるのは「出て行くこと」であって
「動くこと」ではない。**

**3行目は測れただけで、まだ何も変えていない。** 60分・6文字・漏洩の
照合なし・2段階なしという値が分かった状態である。

## 2. 強い点 ―― **壊さないように書き留める**

| | |
|---|---|
| **第三者への通信が1つも無い** | 依存に解析も障害報告も無い。外に出る宛先は Supabase だけ。フォントも自前（`@fontsource`）。**金融系でいちばん多い漏れ方（Sentry・GA が明細と金額を持って行く）が、そもそも経路として存在しない** |
| **service_role キーを使っていない** | コード中に出るのは「使わない理由」の注だけ |
| **鍵を一度もコミットしていない** | 全履歴を JWT 形の文字列とパスワード代入で走査した。当たった2つは**lockfile の sha512** と**環境変数名**（値ではない） |
| `usage_events` | 列の注で**金額と名称を入れないと明示**している |
| `accept_invite` | `security definer` を正しく書いている ―― `set search_path = ''`、`revoke execute from public`、**「招待が無い」と「自分宛でない」で文面を分けない**（id の総当たりで存在を試せないように） |
| 48通りの検査が**本番の project に対して走る** | publishable key と本人セッションで組んであるので、測っている壁が実際の壁である |

**次に何かを足すとき、いちばん戻りやすいのが1行目である。** Sentry・GA・PostHog を入れた瞬間に、銀行明細の摘要と金額が第三者に渡る。入れるなら、何を送らないかを先に決める。

### 2. CSP と応答ヘッダ ── **済（report-only）**

`next.config.ts` に入れた。**本番ビルドにだけ付く**（`pnpm dev` は HMR が
`eval` を使うので、開発サーバーで測ると出るはずのない違反が並ぶ）。

| ヘッダ | 値 | 状態 |
|---|---|---|
| `Content-Security-Policy-Report-Only` | 下記 | **報告のみ。強制は `ENFORCE` を立てる** |
| `X-Content-Type-Options` | `nosniff` | 強制 |
| `Referrer-Policy` | `no-referrer` | 強制。**外に出る宛先が1つも無いので代償が無い** |
| `X-Frame-Options` | `DENY` | 強制。**report-only の `frame-ancestors` は効かない**ので、クリックジャックはこの1本が止めている |
| `Permissions-Policy` | カメラ・マイク・位置ほかを全部 `()` | 強制。どれも使っていない |
| `Strict-Transport-Security` | — | **Vercel が既に付けている**（`max-age=63072000; includeSubDomains; preload`）。二重にしない |

frame-ancestors 'none'; base-uri 'none'; form-action 'self';
object-src 'none'; worker-src 'self'; manifest-src 'self'

#### `'unsafe-inline'` の代償 ── **半分になる**

Next の App Router は RSC のペイロードを**inline script で流す**ので、
`script-src 'self'` だけでは本文が出ない。nonce を使うには middleware が
必要で、**20ルート全部が静的生成から外れる**（いまは `pnpm build` の
出力が全部 ○）。

`'unsafe-inline'` を入れると、**差し込まれたスクリプトの実行は止められない。**
上の表の2行目の守りは、こう変わる：

| | |
|---|---|
| 止められない | **スクリプトが動くこと**（inline なら実行される） |
| 止まる | **出て行くこと** ── `connect-src`（別の宛先への fetch）・`img-src`（画像ビーコン）・`form-action`（別の宛先への送信）・外部スクリプトの読み込み |

**「実行を止める」から「持ち出しを止める」に下がる。** 消えるわけでは
ないが半分である。nonce に進むかは、静的生成20ルートとの取引。

#### 強制に変えるとき

`next.config.ts` の `const ENFORCE = false` を `true` にするだけ。
**その前に、サインインした状態の画面をコンソールを開いて一度踏むこと。**
上の19ページは**サインインしていない**（本番のサイトにこちらからは入らない）
ので、サインイン後にだけ走る読み込みは測れていない。宛先は同じ Supabase
なので新しい違反が出る見込みは薄いが、**見込みは測定ではない。**

#### 測り方 ── **メールを1通も使っていない**

新しいアドレスで登録を試すと、**成功した場合に確認メールが飛ぶ。**
いま確認メールの枠は共有の基線を止めている当の資源なので、測定でそれを
減らさない。代わりに**既に確認済みの負荷試験アカウントのアドレス**に
`signUp` を投げた。GoTrue は確認済みの相手には作りもせず送りもせず、
存在を伏せた応答を返す。**パスワードの検査はその前に走るので、弾かれ方
だけが見える。**

**「その前に走る」ことを先に確かめている。** 逆（先に相手を探す）だと
どんなパスワードでも伏せた応答が返り、**照合が無効でも有効でも同じ結果**
になる。1文字で叩いて長さの文句が返ることを見てから、漏洩の照合を測った
（§2.11）。

#### 読み方

**60分は「盗られたときの影響の長さ」ではない。** refresh token が一緒に
あるので、`localStorage` の中身を持って行かれたら**更新し続けられる。**
上の表の3行目を短くしても、ここは短くならない。

**6文字・漏洩の照合なしは、`docs/セキュリティの状況.md` の1番（公開
リポジトリ）と組で効く。** 有効なアドレスが分かっていて、条件が6文字で、
漏洩の一覧と照合されない。**どちらか一方を閉じれば釣り合いが変わる。**

#### ゲートに入れるか ── **入れるなら形を絞る**

毎回 `pnpm audit` を全部流すと、**本番に出ない23件が毎回赤く出る。**
赤が常態になった検査は読まれなくなる。入れるなら：

```
pnpm audit --prod --audit-level=critical
```

いまこれは**0件で通る。** 今日の critical はこれで止められた。
**判断は利用者側**（CLAUDE.md §2.7 と同じ理由で、勝手にゲートを増やさない）。

### hydration の不一致 ── **本番の経路では起きていない**

本番ビルドで確かめた。`/` `/cashflow` `/pl` の**配られる HTML に
`role="tablist"` が1つも無い**（ローカルの本番ビルドでも、本番のサイトでも
0件）。期間タブは**サインインした後にクライアント側だけで組まれる**ので、
server と client を突き合わせる場面が無い。

出ていたのは `/dev/screens/*` のほう。**あちらは固定値を持っているので、
ビルド時にタブまで組まれる。** いまは `/dev` の shell を `Suspense` で

**security ではないが、出し方が server と client で違うことの印**という
元の読みは正しかった。**違っていたのは場所である。**

足したところ、`/dev/screens/*` の prerender が落ちて `pnpm build` が
