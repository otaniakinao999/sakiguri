| 実装 | その条項を満たすコードが存在する |

## 確認中に見つけたこと（仕様の判断が要る）

### 「実績」モードが未来月の実績を表示しない

`applyMode`（`src/core/pl.ts`）が次のようになっている。

```ts
case "actual":
  return isPast ? actual : null;
```

`isPast` は**年月**での比較なので、今月より後の月に実績があっても「実績」モードでは表示されない。「差異」モードも同様に null になる。

再現した。基準日 2026-09-17・今日 2026-09-25 の状態で 2026年10月に実績を5件入れたところ、「実績」モードの10月列がすべて `·`（データなし）になった。データベースには存在し、キャッシュフロー画面には出ている。

**要件定義書 §3.3 CL-5 手順6 は、モードを4種と定めているだけで「実績モードは未来月を隠す」とは書いていない。** 書かれているのは `実績+予定` の定義（過去月は実績、未来月は予定）だけである。

判断が要る。

- **意図どおりなら**：仕様に明記すべき。未来月の実績は存在しうる（翌月分の家賃を前払いした、CSVに先日付の行があった、など）。隠すなら理由を残す
- **意図でないなら**：`case "actual": return actual;` に直す。`diff` は未来月で比較する意味が薄いので現状のままでよい

実害の程度：前払いした支出が「実績」モードで見えない。年月別収支の合計が現金の動きと合わなくなるが、`実績+予定` モード（既定）では未来月は予定を出すので、既定の画面では気づけない。

修正は1行だが、**仕様に書かれていないことを実装しない**（CLAUDE.md §1）ため、判断を待って対応する。
