## 0. 共通レイアウト

```
<body class="bg-muted">            ← 画面の地は bg-muted
┌ Sidebar inset (p-2 = 8px) ┐┌ Main ───────────────────────────────┐
│ ┌ SideNav 224px ────────┐ ││ PageHeader（ダッシュボード以外）      │
│ │ bg-primary rounded-lg │ ││ Content: pt-6 px-8 pb-8, gap-6       │
│ └───────────────────────┘ ││   Panel（bg-card rounded-lg p-6）…   │
└───────────────────────────┘└──────────────────────────────────────┘
```

- **画面幅：** デザインは 1440px で作っています。最小は 1280px を想定し、Main は可変幅です。
- **サイドバー：** 画面の高さに合わせて `sticky top-0 h-screen` で固定します。Main だけがスクロールします。
- **パネルの並べ方：**
  - パネル同士の間隔は 24px（`gap-6`）。
  - 2カラムにする画面では、右カラムを固定幅（例：口座・カード 420px）、左カラムを `flex-1` にします。
- **数値の列：** すべて右揃えにして `.num` を付けます。
- **密度：** 大きな表（月次資金繰り表・年月別 収支・入出金予定表）は、表を囲む要素に `data-density="compact"` を付けます。
- **角丸の使い分け：**

| 角丸 | 値 | 使う場所 |
|---|---|---|
| sm | 6px | タグ、Callout |
| md | 8px | ボタン、入力欄、NavItem、タブ |
| lg | 12px | パネル、サイドバー |
| xl | 12px | ダイアログ |

- **PageHeader の右側（全画面共通）：** 次の4つの値を表示します。値は画面ごとに変わらず、サーバーで計算した同じ値を使います。

| 項目 | 値 |
|---|---|
| 今日の残高 | ¥2,847,300 |
| 30日後 | ¥2,412,800 |
| 90日後 | ¥1,905,200 |
| カード未払 | ¥248,600 |

## 1. 用語（UIで使う言葉）

| 用語 | 意味 |
|---|---|
| 予定 | まだ起きていない入出金。定期項目と単発の予定から生成される |
| 実績 | 実際に起きた入出金。手入力または CSV で登録される |
| 消し込み・照合 | 予定と実績を結びつけること。結びつけると予定は消える |
| 基準日 | 残高を計算し始める日。口座の残高は「基準日時点の残高」として持つ |
| 生活防衛ライン | これより残高が下がると危険とみなすライン（例：¥1,500,000） |
| 区分 | 収入 / 固定費 / 変動費 / 振替。CSV取込の画面では「カード引落」も区分として出てくる |
| 振替 | 自分の口座間の移動。損益に含めず、合計残高も変えない |
| カード：確定金額 / 未確定分 | 確定金額は、基準日のあと最初の引き落とし日に計上される。未確定分は、その次の引き落とし日に計上される |
| 事業割合 | 費用のうち事業で使った割合（%） |
